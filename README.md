# HTML + Tailwind CSS Assignment

## WORK

### Git tasks

- Create your personal fork of this repository
- Clone your fork to your local machine
- Create a new branch and switch to it. Make all changes on your feature branch.
- Push your completed work to your fork on GitHub.
- Open a Pull Request to the original repository after completing the assignment.

### Environment Tasks

- Create the project folder and open it in VS Code.
- Create an `index.html` file.
- Set up Tailwind CSS in the project.
- Make sure Tailwind CSS is working correctly before starting the tasks.

---

## Practice Tasks

This assignment keeps most work for students.

Complete a set of small HTML and Tailwind CSS tasks and then use that knowledge to complete the main task.

All practice tasks should be completed in the `practice_tasks/` folder.

### Practice Task 1 — HTML Structure

Create:

`practice_tasks/task1.html`

Build a basic HTML page containing:

- A proper `<!DOCTYPE html>` declaration
- `<html>`, `<head>`, and `<body>`
- A page title
- A main heading
- Two paragraphs
- An unordered list containing at least 3 items
- A link
- An image

Use HTML elements where appropriate.

---

### Practice Task 2 — Tailwind Typography

Create:

`practice_tasks/task2.html`

Create a simple article section using Tailwind CSS.

The page should contain:

- A large heading
- A subtitle
- Two paragraphs
- A highlighted text section

Apply Tailwind classes for:

- Font size
- Font weight
- Text alignment
- Text color
- Line height
- Spacing

The page should be visually readable and properly spaced.

---

### Practice Task 3 — Cards

Create:

`practice_tasks/task3.html`

Create **three sections in one page** representing services, products, or skills.

Each section should contain:

- An icon or image
- A title
- A short description
- A button

Use Tailwind CSS to add:

- Background colors
- Padding
- Rounded corners
- Borders
- Spacing

The sections should look good.

---

### Practice Task 4 — Flexbox and Grid

Create:

`practice_tasks/task4.html`

Create a section containing at least **6 items**.

Use Tailwind CSS Flexbox or Grid classes to arrange the items.

Requirements:

- The layout should display multiple columns on larger screens.
- There should be proper spacing between items.
- Items should have consistent styling.


### Main Task — Personal Portfolio Website

Create a folder using your name.

For example:

Kewir_Jewel/

Inside the folder, create:

Kewir_Jewel/
│
├── index.html
└── assets/

Build a responsive personal portfolio website using only:

HTML
Tailwind CSS

Required Sections

Your portfolio must contain the following sections:

1. Navigation Bar

The navigation bar should contain:

Your name 
Home
About
Skills
Projects
Contact

The navigation links should point to their respective sections on the page.

2. Hero Section

Create a professional hero section containing:

Your name
Your role/title
A short introduction
A profile image(it should display like a halfshot)
A primary button such as "View My Work"
A secondary button such as "Contact Me"

The section should look good on both desktop and mobile.

3. About Section

Create an About section containing:

A section heading
A short biography(2 paragraphs about you)
Your interests or career goals
An image or visual element

Use proper spacing and typography.

4. Skills Section

Create a skills section displaying at least 6 skills.

Examples:

HTML
Tailwind CSS
JavaScript
React
Git
GitHub

Each skill should be displayed in a visually appealing container, or progress-style component.

5. Projects Section

Create a Projects section containing at least 3 projects.

Each project container should contain:

Project image
Project name
Short description
Technologies used
"View Project" button

Use Tailwind CSS to make each project container visually consistent.

6. Contact Section

Create a contact section containing:

Email
Phone number
Location
Social media links
A contact form

The contact form should contain:

Name input
Email input
Subject input
Message textarea
Submit button

You do not need to implement backend functionality.
the contact form should have its own border and centralised

7. Footer

Create a footer containing:

Your name
Copyright text
Social links(all your social media links)
Navigation links (that is your sections you created above)

Your project must demonstrate proper use of Tailwind CSS.

You should use Tailwind classes for:

Colors
Typography
Padding
Margin
Width and height
Flexbox
Grid
Borders
Border radius
Hover effects(especially for button, they should all have hover effect)

Your website should:

Use semantic HTML.
Have clean and organized HTML.
Have consistent spacing.
Have readable typography.
Have a consistent design.
Have working navigation links.
Have no broken images.
Have no unnecessary inline CSS.
Use Tailwind CSS utilities instead of writing large amounts of custom CSS.
